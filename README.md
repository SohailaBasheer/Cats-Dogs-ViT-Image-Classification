
# Cats vs Dogs Image Classification

## Project Overview
This project uses a fine-tuned Vision Transformer (ViT) model to classify images into two categories: Cat and Dog.

## Model
- Pretrained Model: google/vit-base-patch16-224
- Architecture: Vision Transformer (ViT)
- Fine-tuning: Transfer Learning
- Dataset: Cats vs Dogs
- Test Accuracy: 99.72%

## Technologies Used
- Python
- PyTorch
- Hugging Face Transformers
- Streamlit
- Google Colab

## Hugging Face Model
https://huggingface.co/Sohaila16/cats-dogs-vit-classifier

## Features
- Upload a Cat or Dog image
- Predict the image category
- Display classification results
